## Границы проверки

Фронтенд соответствует текущим исходникам по результату воспроизводимой
сборки. Для бэкенда подтверждено совпадение публичного API-контракта.
HTTP-проверка не подтверждает побайтное совпадение серверных Python-файлов,
версию миграций БД, содержимое `.env`, работу фоновых синхронизаций или
успешный вход доменного пользователя. Для этого нужен доступ к серверным
файлам и авторизованной сессии. Режим `KERBEROS_MODE` по ответам не установлен.

HTTPS-запросы выполнены через Python urllib с отключённой проверкой
сертификата: системный curl завершился ошибкой Schannel
`SEC_E_NO_CREDENTIALS`. Доверие к сертификату и соответствие имени узла
не проверены; настройки TLS сервера не изменялись.

Использовались только GET-запросы к стенду. Изменения данных, запуск
синхронизаций, установка миграций и повторное развёртывание не выполнялись.
Версия `0.1.0` в API сама по себе не идентифицирует ревизию кода.
